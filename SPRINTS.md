# SPRINTS.md — План спринтов Finance Cockpit

Спринт = несколько итераций с единой целью. Ревью Александра — на границе спринта.

## Принцип работы
- Claude Code берёт задачи из BACKLOG.md по порядку приоритета внутри текущего спринта
- Каждая задача: реализация → eval → build → commit → отметка [x]
- Спринт закрыт когда все 🔴 и 🟡 задачи выполнены
- На закрытии спринта — Александр делает ревью, корректирует следующий

---

## SPRINT 1 — Бот-бухгалтер (ТЕКУЩИЙ)
**Цель:** Бот становится проактивным финансовым советником, который считает экономическую целесообразность решений и сам приходит с рекомендациями.

**Definition of Done:**
- Бот отвечает на «стоит ли купить X в кредит» полным расчётом (переплата, альтернативы, рекомендация)
- Вечерний cron присылает проактивные рекомендации по оптимизации (кэш→долг)
- Income events создаются автоматически по датам
- Eval-харнесс покрывает 15+ сценариев

**Срез после спринта:** Александр тестирует на реальных решениях (макбук-кейс), даёт обратную связь.

---

## SPRINT 2 — Рабочий модуль (CRM АТОН)
**Цель:** Бот ведёт базу клиентов и сделок, напоминает о касаниях, даёт утреннюю аналитику.

**Definition of Done:**
- Клиенты хранятся с полной карточкой
- Бот добавляет/обновляет клиента из естественной речи
- «С кем давно не общался» работает
- Утренний дайджест включает рабочие приоритеты

---

## SPRINT 3 — Планирование
**Цель:** Система целей по горизонтам + Google Calendar + дневные приоритеты.

**Definition of Done:**
- Цели по 6 горизонтам (день…5 лет)
- Календарь читается/пишется через бота
- Утром — 3 приоритета дня

---

## SPRINT 4 — База знаний
**Цель:** Семантический поиск по рабочим заметкам и market intel.

**Definition of Done:**
- Заметки сохраняются и ищутся по смыслу (pgvector)
- Бот отвечает на основе сохранённых знаний

---
